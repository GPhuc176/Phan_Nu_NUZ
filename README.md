# Phấn Nụ NUZ Website

A Vietnamese-language storytelling website for **"Nụ Xưa, Nét Nay"**, a student communication project that promotes Phấn Nụ, a traditional natural cosmetic from the royal court of Huế. Built with HTML, CSS, and vanilla JavaScript.

## Features

- **Scroll-controlled animation:** a 151-frame canvas animation of a Phấn Nụ tablet blooming, controlled by mouse scroll or a slider on mobile.
- **Interactive process viewer:** a step-by-step card showing the 7 stages of handmade Phấn Nụ, with expandable details.
- **Shape explorer:** a tab switcher comparing the 7-tier Phấn Nụ with Thiên Mụ Pagoda.
- **Heritage timeline:** from the Nguyễn court to the present day.
- **Ingredients and benefits:** photo cards with detail pop-ups for each benefit.
- **Story reader:** "Nụ kể chuyện", a blog section of 7 stories with a modal reader and previous/next navigation.
- **Mascot profile:** a character card for the brand mascot, Bé Nụ.
- **Student journey:** the team's visit to the Phấn Nụ workshop in Huế, linked to the full video on Facebook.
- **Mini game:** a desktop-only game, with a friendly notice shown on mobile.
- **Polish:** page loader, typing effect, scroll-reveal animations, responsive layout, feedback form, and Google Analytics.

## Getting Started

No build step needed. Clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/GPhuc176/Phan_Nu_NUZ.git
cd Phan_Nu_NUZ
```

To publish for free, enable **GitHub Pages** in Settings → Pages and select the `main` branch.
